# wiki/: geprüftes Wissen

Hier steht, was Sie in vier Wochen noch nachschlagen wollen: Begriffe, Abläufe, Ansprechstellen, Entscheidungsgründe. Claude pflegt die Seiten, Sie prüfen sie.

Der Ordner folgt dem Open Knowledge Format (OKF) in Version 0.3, einem offenen Format für Wissen aus Markdown-Dateien. So können auch andere Programme und KI-Werkzeuge das Wiki lesen. Der Kopf oben in dieser Datei beschreibt das ganze Wiki; `license: LicenseRef-intern` heißt „nur für den eigenen Gebrauch“.

- Eine Seite je Thema, kurz und mit Quelle. Neue Seiten entstehen als Kopie von [Vorlage für neue Seiten](_vorlage.md).
- Jede Seite beginnt mit einem Kopf zwischen zwei Zeilen `---` (die Frontmatter). Pflicht ist dort nur `type`.
- Jede neue Seite bekommt unten eine Zeile: `- [Titel](datei.md) - ein Satz, worum es geht`. Dazu kommt ein Eintrag in [log.md](log.md).
- Verweise auf andere Seiten sind normale Markdown-Links wie `[Titel](datei.md)`, keine Links mit doppelten eckigen Klammern.
- Was nur heute gilt, gehört nicht hierher, sondern nach `brainstorms/`.
